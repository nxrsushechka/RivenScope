# Обновление и откат

Удалённый release feed не настроен, репозиторий не опубликован. Приложение не делает
фиктивную проверку «последней версии» и не запускает загруженный код.

## Локальное обновление

1. Сделайте backup через GUI и закройте приложение.
2. Обновите исходники из доверенной локальной копии.
3. Выполните из каталога проекта:

```bash
QT_QPA_PLATFORM=offscreen PYTHONPATH=src python -m unittest discover -s tests -t . -v
.venv/bin/python tools/build_release.py
python tools/install.py
```

Установщик проверяет staging release до переключения `current`, сохраняет прежний
release в `previous`, не трогает XDG database/config/state. Данные мигрируют при
запуске; перед миграцией существующей схемы создаётся резервная копия.

При обновлении системного Python/Qt через Omarchy проверьте `rivenscope --version`
и обычный запуск. Приложение использует дистрибутивный PySide6, поэтому системные
обновления Python и PySide6 должны выполняться согласованно средствами дистрибутива.

## Откат

Закройте приложение. Предыдущий release находится по ссылке
`~/.local/share/rivenscope-app/previous`.
Можно временно запустить его без переключения:

```bash
python -I ~/.local/share/rivenscope-app/previous/launch.py
```

Если новая версия изменила схему БД, старая версия может отказаться её открывать.
В этом случае используйте backup, сделанный перед обновлением; не понижайте
`PRAGMA user_version` вручную. В версии 0.1.0 схема = 2.

Для постоянного отката соберите/установите прежние исходники тем же установщиком.
Это безопаснее ручного удаления releases. Данные не удаляются установщиком.
