# Реальные ограничения версии 0.1.0

## Критическое внешнее ограничение

На 2026-11-09 не подтверждён публичный поддерживаемый endpoint поиска/получения
Riven contracts. Подробности и первичные источники — [API_FEASIBILITY](API_FEASIBILITY.md).
Успешный HTTP 200 справочника не подтверждает наличие контрактного API.

Поэтому **не реализована работающая живая интеграция контрактов**, а следовательно:

| Возможность | Фактический статус |
|---|---|
| Global Market Monitor | Контрактный охват = 0, полный размер рынка неизвестен; все оружия непроверены |
| Custom Watchlists | Создание/редактирование/дублирование/импорт/экспорт/фильтры работают локально; сетевое обновление заблокировано |
| Реальные объявления и продавцы | Не загружаются; каталоги не содержат rolled stats/цен/ставок/продавцов |
| Новые/обновлённые/исчезнувшие контракты | Локальный snapshot/dedup engine проверен, но не подключён к реальному контрактному источнику |
| Оценки цен / deals / risk | Статистический алгоритм проверен на контролируемых сценариях; реальная рыночная точность не проверена |
| История цен / графики | Собственная SQLite-история и визуализация реализованы; в новой установке история пуста |
| Торговые уведомления | Каналы и suppression работают; автоматический поток реальных deal events заблокирован |
| WebSocket Riven feed | Не документирован; newOrders не используется как замена |
| История завершённых Riven-сделок | Не доступна, цены объявлений не считаются продажами |
| Copy trade message | Выключено: нет подтверждённого актуального шаблона сообщения контракта с идентификацией приложения |

Это не обходится скрытым v1 fallback, скрейпингом сайта или догадками о маршрутах.
В поставке нет тестовых контрактов, фиктивных оценок, seller data или искусственных графиков.

## Ограничения локальной модели

- Оценки описывают **asking prices**, не гарантированный resale price или доходность.
- Модель консервативна: одинаковое оружие, rank, disposition, measurement context,
  набор атрибутов со знаками. Она не умеет доказательно переносить ценность между
  разными наборами характеристик/вариантами оружия и возвращает Insufficient data.
- Полезность отрицательного эффекта контролируется совпадением его идентичности;
  самостоятельной обученной модели utility нет. Ручные «метовые» премии не выдуманы.
- Веса расстояния/давности/рероллов — явно указанные эвристики, не подтверждённые
  рынком коэффициенты. Confidence — показатель качества выборки, не вероятность прибыли.
- Неизвестный seller/display context снижает достоверность; модель нельзя считать
  валидированной на рынке до появления достаточной реальной выборки.
- Для large-data UX применяется страница до 10 000 строк; сравнения используют
  загруженную страницу совместимых наблюдений. Полнота выборки не обещается.
- Графики читают до 20 000 последних снимков, рисуют до 2 000 точек; нет бесконечной
  загрузки всей истории в UI. Исторические события не доказывают факт продажи.
- Fingerprint повторной публикации — предположение, не доказательство идентичности.
- Исчезновение можно маркировать лишь для полного подтверждённого snapshot; частичная
  поисковая выдача не позволяет делать такой вывод. Ни один текущий источник этого не даёт.

## Непроверенное и последующая работа

- Реальные contract response parsing, server-side filtering, live bid/price/status
  events, contract coverage и latency — **невозможно проверить без поддерживаемого API**.
- End-to-end deal alerts/сравнение рыночных Riven/торговое сообщение — заблокированы.
- Crossplay headers отправляются корректно, но фактическое покрытие PC cross-trading
  нельзя подтвердить на справочниках.
- Удалённые обновления/подпись релизов не настроены: нет опубликованного источника.
- Многочасовой/многодневный реальный мониторинг контрактов не проверен. Контролируемый
  soak не заменяет длительную рыночную эксплуатацию.
- Фактическую слышимость звука и восприятие уведомления пользователем автоматический
  тест не подтверждает; проверяются доставка сервису и завершение аудиопайплайна.

## Приоритет следующих улучшений

1. Получить официальный документированный доступ к contracts у Warframe Market.
2. Добавить adapter, реальные contract fixtures и live end-to-end тесты с соблюдением ToS.
3. Калибровать estimator на накопленной истории объявлений, не выдавая её за сделки.
4. Подтвердить точный trade-message template и включить копирование с названием приложения.
5. Развивать индексируемое постраничное сравнение больших коллекций и длительные soak-тесты.

Полное соответствие исходной Definition of Done не заявляется.
