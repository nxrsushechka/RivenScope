# Реальные ограничения версии 0.2.0

## Источник объявлений

Реализован экспериментальный read-only `GET /v1/auctions/search`. Работа endpoint
подтверждена предоставленным пользователем HTTP 200 / JSON со 100 объявлениями
Torid от 10 ноября 2026. Официальная поддержка legacy v1 не подтверждена: WFM
объявляет v1 deprecated/unsupported. Подробнее: [READINESS_0.2.0](READINESS_0.2.0.md).
В cloud тот же маршрут возвращает Cloudflare challenge; controlled replay не
заменяет live-проверку. Режим выключен по умолчанию и включается в Settings.

| Возможность | Фактический статус |
|---|---|
| Global / watchlist polling | Есть opt-in обход оружий, общий лимит 10/мин и приоритеты; полнота рынка неизвестна |
| Объявления, rolled attributes, продавцы, ставки | Парсер и GUI проверены на 100 реальных записях; текущая доступность продавцов не гарантируется |
| Прямые продажи и выкуп | Код различает типы; предоставленная live-выборка не содержит direct/buyout, нужны дополнительные реальные ответы |
| Новые записи и price/status/bid changes | Локальный engine подключён к partial responses; live динамика изменений ещё не проверена |
| Исчезновение/продажа | Из пропуска в search ничего не выводится: полнота/пагинация не подтверждены |
| Оценки цены / прибыль / deals | Для legacy raw context возвращается Insufficient data; рыночная точность не проверена |
| История / графики | Накопление собственных наблюдений; ставки отделены от asking prices; искусственной истории нет |
| Trade alerts | Каналы и suppression проверены локально; end-to-end реальные deal alerts не подтверждены |
| Riven WebSocket | Документированного feed для контрактов не найдено; newOrders не заменяет его |
| Copy trade message | Выключено до подтверждения текущего шаблона |
| Автоматические покупки/ставки/сообщения | Не реализуются |

## Ограничения локальной модели и данных

- Числовой raw roll context и применённый disposition не выводятся из текущего
  weapon catalog. До подтверждения нормализации valuation для legacy отключена
  отсутствующими обязательными данными, произвольные цены не генерируются.
- Объяснимая модель проверена на контролируемых данных: одинаковое оружие, rank,
  disposition, measurement context, набор характеристик со знаками. Asking prices
  не являются verified transactions, confidence не является вероятностью прибыли.
- Веса similarity/recency/rerolls — явные эвристики, не подтверждённые рынком факты.
- Страница таблицы содержит до 250 наблюдений перед локальной фильтрацией.
  Comparables независимо от страницы ограничены 10 000 последними совместимыми asks.
- Текущее распределение использует до 10 000 свежих active direct asks. Исторические
  графики читают до 20 000 snapshots, рисуют до 2 000 точек. Старые записи сохраняются
  до явной очистки и не считаются подтверждённо актуальными.
- При 420 оружиях и 10 запросах/мин обход занимает минимум 42 минуты без учёта
  каталога/retries. Если выбранные фильтры не попали в частичную выдачу, совпадение
  может быть пропущено. Полный рынок и мгновенное обнаружение не обещаются.
- Статус продавца самозаявленный; relist fingerprint — гипотеза, не доказательство.

## Непроверенное

- Full live pipeline новой версии на Omarchy, длительное наблюдение настоящего рынка.
- Pagination/лимит выдачи, numerical normalization, реальные direct/buyout snapshots.
- Native Wayland/menu/audio/desktop notifications 0.2.0 в этой cloud-среде.
- Подписанный remote update feed и история завершённых Riven-сделок отсутствуют.

Исходная полная Definition of Done не выполнена. Следующие действия перечислены
в [READINESS_0.2.0](READINESS_0.2.0.md); исторические отчёты 0.1.x не являются проверкой
нового live-мониторинга.
