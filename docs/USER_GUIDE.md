# Руководство пользователя

## Первый запуск

Откройте **RivenScope** в меню Omarchy или выполните `rivenscope`.
На **Dashboard** нажмите **Start catalog sync**. Первый запрос проверяет версии,
затем загружаются оружие и определения характеристик. Между запросами выдерживается
не менее 6,1 секунды. Повторное нажатие после остановки использует кэш.

**Stop** отменяет активные запросы и очередь. Закрытие окна завершает приложение.
Следующий запуск не включает мониторинг автоматически. Автозапуска Linux нет.

## Что доступно сейчас

### Dashboard
Реальное состояние планировщика, бюджет запросов, время обновления справочников,
число сохранённых пресетов и локальных наблюдений. Market coverage не означает
полноту рынка: сейчас источника контрактов нет, число проверенных контрактов — ноль.

### Market Monitor → Weapon catalog
Настоящие метаданные Warframe Market. Поиск фильтрует строки локально без API-вызовов.
Выберите оружие: справа отображаются disposition, тип и допустимые атрибуты.
**Base weapon MR** — ранг самого оружия, не требование конкретного Riven.

### Watchlists
Нажмите **+ New watchlist**, задайте имя, приоритет 1–10 и оружие/группу оружия.
Отсутствие выбранных оружий означает все оружия; категория дополнительно ограничивает поиск.

Во вкладке **Conditions**:
- Выберите группу, затем **+ Condition** или **+ Group**.
- Группы AND/OR могут быть вложенными. NOT требует ровно одного дочернего условия.
- Двойной щелчок редактирует условие/группу.
- Positive/Negative выбирают знак эффекта, который не всегда совпадает со знаком числа.
- Диапазон задаётся двумя условиями, например `Price at least 200` AND `Price at most 1500`.
- Для отсутствующего атрибута используйте **is absent**. Неизвестное значение не
  удовлетворяет обычным сравнениям и не становится совпадением из-за NOT.
- Weapon/category сравниваются по API slug; оружие удобнее выбирать в первой вкладке.

Сохранение проверяет типы, ограничения атрибутов и совместимость с выбранным оружием.
**Alerts & risk** сохраняет отдельные настройки пресета. Число локальных пресетов
не ограничено; один файл импорта ограничен 10 МБ / 10 000 пресетов для защиты загрузки.
**Duplicate**, **Enable / disable**, **Import**, **Export** работают локально.
При импорте назначаются новые ID — существующие пресеты не перезаписываются.

Контрактные запросы для пресетов сейчас не выполняются: API capability unavailable.

## Локальные аналитические инструменты

### Contracts / Riven details
В новой установке таблица пуста. В ней никогда не появятся записанные тестовые примеры.
Для совместимой восстановленной истории доступны поиск, сортировка, локальный фильтр,
страницы по 10 000 наблюдений, детали, история, risk и список comparable IDs.
Ширина/порядок столбцов, размер окна и локальный фильтр сохраняются.

Оценщик сравнивает одно оружие, один rank/disposition/display context и одинаковый
набор эффектов со знаками; числовые значения учитываются через относительное расстояние.
Отбрасываются устаревшие записи, дубликаты, повторения одного продавца и ценовые выбросы.
При недостаточной выборке возвращается **Insufficient data**.

**Asking-price estimate** — оценка по запрашиваемым ценам, не доказанная цена продажи.
Potential gross profit = estimated value − acquisition price. Интервал — разброс
сопоставимых предложений, а не обещание продажи. Налог, ликвидность и срок реализации неизвестны.
Стартовые ставки никогда не используются как фиксированная цена приобретения.

### Analytics
Графики собственных наблюдений: запрашиваемые цены, распределение цен, отдельные
аукционные ставки и число результатов поиска. История не восстанавливается из воздуха.
Разные роллы внутри одного оружия не равнозначны; сводные распределения описательные.

### Notifications
История сохраняется. Настройте in-app, desktop, sound и highlighting в **Settings**
или отдельно для пресета. Для звука выберите локальный WAV-файл. Статусы продавца,
уведомления о новых/существующих объявлениях и изменениях цены настраиваются отдельно.
Повторное событие, включая пересечение пресетов, не порождает дубликат.
**Test notification channels** явно маркирует тест и не создаёт рыночное событие.
Без contract source настоящие торговые оповещения не формируются.

### Trading actions
Для подтверждённой локальной записи доступны открытие WFM, копирование URL/имени.
**Copy trade message** выключено: актуальный формат контрактного сообщения не
подтверждён; используйте официальный текст на сайте. Сообщения никогда не отправляются
автоматически. Статус продавца — самозаявленный, не гарантия готовности к обмену.

## Настройки, данные и резервные копии

- **Settings → Preferences**: interval (не менее часа для версий справочника),
  приоритет, плотность таблицы, Conservative/Balanced/Aggressive и ручные пороги.
- **Data & backup → Back up database…**: согласованная копия SQLite с integrity check.
- **Restore database…**: явное подтверждение, остановка синхронизации, проверка формата
  и создание `before-restore-<timestamp>.sqlite` перед заменой.
- При повреждённой базе исходные файлы сохраняются в `damaged-<timestamp>/`.
- **Prune old snapshots…** удаляет старые снимки только после подтверждения, сохраняя
  последние снимки и идентификаторы событий для дедупликации.
- Экспорт наблюдений CSV/JSON расположен в **Market Monitor → Contracts**. CSV защищён
  от формул из внешних текстовых полей. Пустая база экспортируется как пустая, без примеров.

Удалённый источник обновлений не настроен. Инструкция: [UPDATING](UPDATING.md).
